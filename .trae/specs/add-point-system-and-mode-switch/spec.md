# 点位系统与运动参数模式切换 Spec

## Why
当前运动模块（直线运动、力控圆弧）只能直接输入坐标数值，无法引用预定义点位或相机识别结果。需要引入点位管理系统，支持预定义/动态点位，并让运动模块能在"直接坐标"和"点位引用"两种模式间切换。

## What Changes
- 修改 GUI 相机连接区域布局：状态标签和连接/断开按钮分行显示
- 新增点位管理系统：3 个默认点位（p_d435i、p_u405、p_n405）+ 用户自定义点位
- 相机识别模块执行后自动更新对应点位值
- 新增点位编辑 UI：在运动编辑选项卡中增加点位列表，支持增加/删除/编辑点位
- 点位支持相对模式：可定义为相对于另一个点位的偏移
- 修改直线运动和力控圆弧参数编辑：增加"坐标模式/点位模式"切换

## Impact
- Affected code: `gui_app.py`, `config_manager.py`, `config.json`
- Affected behavior: 运动模块参数编辑方式、相机识别结果存储方式

## ADDED Requirements

### Requirement: 相机连接区域布局调整
主界面相机连接区域 SHALL 将状态标签和按钮分行显示：每台相机第一行显示状态标签，第二行显示连接和断开按钮。

#### Scenario: D435i 布局
- **WHEN** 用户查看 D435i 相机区域
- **THEN** 第一行显示"D435i: 未连接/已连接"状态标签（占满整行），第二行显示"连接"和"断开"两个按钮并排

#### Scenario: D405 布局
- **WHEN** 用户查看 D405 相机区域
- **THEN** 第一行显示"D405: 未连接/已连接"状态标签（占满整行），第二行显示"连接"和"断开"两个按钮并排

### Requirement: 点位管理系统
系统 SHALL 提供点位管理功能，维护一个全局点位字典，每个点位包含名称、坐标值、是否相对点位及相对基准。

#### Scenario: 默认点位
- **WHEN** 系统启动
- **THEN** 自动创建 3 个默认点位：
  - `p_d435i`：D435i 识别中心点，初始值 `[0,0,0,0,0,0]`，由 D435i 相机识别自动更新
  - `p_u405`：D405 识别上方点（柄端），初始值 `[0,0,0,0,0,0]`，由 D405 相机识别自动更新
  - `p_n405`：D405 识别下方点（钩尖端），初始值 `[0,0,0,0,0,0]`，由 D405 相机识别自动更新

#### Scenario: 相机识别更新点位
- **WHEN** 流程中执行 D435i 相机识别模块
- **THEN** 识别结果自动写入 `p_d435i` 点位（6维：X,Y,Z,Rx,Ry,Rz）
- **WHEN** 流程中执行 D405 相机识别模块
- **THEN** 柄端坐标写入 `p_u405`，钩尖坐标写入 `p_n405`，抓取位置写入 `p_d435i`（兼容）

#### Scenario: 用户自定义点位
- **WHEN** 用户添加新点位
- **THEN** 点位名称唯一，坐标值可为绝对坐标或相对于另一点位的偏移

### Requirement: 点位编辑 UI
运动编辑选项卡 SHALL 包含点位编辑区域，显示所有点位列表，支持增加、删除、编辑操作。

#### Scenario: 查看点位列表
- **WHEN** 用户切换到运动编辑选项卡
- **THEN** 显示所有点位名称及当前坐标值

#### Scenario: 添加点位
- **WHEN** 用户点击"添加点位"并输入名称
- **THEN** 新点位加入列表，初始坐标 `[0,0,0,0,0,0]`

#### Scenario: 删除点位
- **WHEN** 用户选中一个非默认点位并点击"删除点位"
- **THEN** 该点位被移除；默认点位（p_d435i、p_u405、p_n405）不可删除

#### Scenario: 编辑点位坐标
- **WHEN** 用户选中一个点位并编辑坐标值
- **THEN** 坐标值更新；若该点位被其他相对点位引用，相对点位计算值自动更新

#### Scenario: 设置相对点位
- **WHEN** 用户将点位设为相对模式并选择基准点位和偏移量
- **THEN** 该点位的实际坐标 = 基准点位坐标 + 偏移量；基准点位变化时自动重新计算

### Requirement: 运动模块参数模式切换
直线运动和力控圆弧的参数编辑 SHALL 支持"坐标模式"和"点位模式"切换。

#### Scenario: 坐标模式（默认）
- **WHEN** 运动模块参数编辑处于坐标模式
- **THEN** 显示与现有行为一致的数值输入框（偏移值、圆心坐标等）

#### Scenario: 点位模式
- **WHEN** 用户切换到点位模式
- **THEN** 显示点位选择下拉框，用户选择一个已定义的点位作为目标位置

#### Scenario: 模式切换保留参数
- **WHEN** 用户在两种模式间切换
- **THEN** 各模式下的参数独立保存，切换时不丢失

### Requirement: 点位持久化
点位数据 SHALL 持久化存储到 config.json，程序重启后自动加载。

#### Scenario: 保存点位
- **WHEN** 点位数据发生变化（编辑、识别更新、添加、删除）
- **THEN** 变更自动写入 config.json

#### Scenario: 加载点位
- **WHEN** 程序启动
- **THEN** 从 config.json 加载点位数据；若文件中无点位数据则使用默认值

## MODIFIED Requirements

### Requirement: config.json 结构
config.json SHALL 新增 `points` 字段存储点位数据：
```json
{
  "points": {
    "p_d435i": {
      "coords": [0, 0, 0, 0, 0, 0],
      "is_relative": false,
      "relative_to": null,
      "offset": [0, 0, 0, 0, 0, 0],
      "is_default": true
    },
    "p_u405": {
      "coords": [0, 0, 0, 0, 0, 0],
      "is_relative": false,
      "relative_to": null,
      "offset": [0, 0, 0, 0, 0, 0],
      "is_default": true
    },
    "p_n405": {
      "coords": [0, 0, 0, 0, 0, 0],
      "is_relative": false,
      "relative_to": null,
      "offset": [0, 0, 0, 0, 0, 0],
      "is_default": true
    }
  }
}
```

### Requirement: 直线运动参数编辑
直线运动参数编辑区域 SHALL 新增模式切换控件（坐标模式/点位模式），点位模式下显示点位选择下拉框。

### Requirement: 力控圆弧参数编辑
力控圆弧参数编辑区域 SHALL 新增模式切换控件（坐标模式/点位模式），点位模式下圆心使用选中的点位坐标。

### Requirement: FlowThread 运动模块执行
FlowThread 中直线运动和力控圆弧模块 SHALL 支持从点位名称解析坐标：
- 若参数中包含 `point_name`，从全局点位字典获取坐标
- 若点位为相对点位，自动计算实际坐标
- 若点位不存在，报错终止

## REMOVED Requirements
无移除的需求。
