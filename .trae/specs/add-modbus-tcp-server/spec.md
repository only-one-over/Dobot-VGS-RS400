# Modbus TCP 服务器通信 Spec

## Why
机械臂工控机需要作为 Modbus TCP 服务器（Slave），让底盘工控机（Master）能通过 Modbus 协议发送控制指令（复位、回安全位、提钩、目标位置等）并读取机械臂状态反馈。

## What Changes
- 新建 `modbus_server.py` 模块，使用 pymodbus 实现异步 Modbus TCP 服务器
- 服务器维护寄存器映射表，响应底盘的读写请求
- 收到写寄存器时触发回调，执行对应机械臂动作（复位/回安全位/提钩/移动）
- 定时更新状态寄存器（状态反馈、故障代码、当前位置等）
- GUI 新增"Modbus通信"选项卡，显示连接状态和寄存器实时数据

## Impact
- Affected code:
  - 新增 `dobot_move/modbus_server.py`
  - `dobot_move/gui_app.py` - 新增 Modbus 选项卡
  - `dobot_move/robot_controller.py` - 添加 Modbus 回调处理方法

## ADDED Requirements

### Requirement: Modbus TCP 服务器
系统 SHALL 在机械臂端运行 Modbus TCP 服务器，监听端口 502（可配置），支持功能码 03（读保持寄存器）和 06/16（写单个/多个寄存器）。

#### Scenario: 服务器启动
- **WHEN** 用户点击"启动Modbus服务"
- **THEN** 服务器在指定端口监听，等待底盘连接

### Requirement: 寄存器映射
服务器 SHALL 维护以下寄存器映射：

| 寄存器地址 | 类型 | 方向 | 含义 |
|-----------|------|------|------|
| 50001 | U16 | 底盘写 | 命令：1=复位, 2=回安全位, 3=自动提钩 |
| 50003 | U16 | 底盘写 | 提钩使能：1=使能, 0=禁用 |
| 50010-50011 | F32 | 底盘写 | X目标位置 |
| 50012-50013 | F32 | 底盘写 | Y目标位置 |
| 50014-50015 | F32 | 底盘写 | Z目标位置 |
| 50016-50017 | F32 | 底盘写 | 末端旋转角度 |
| 50018-50019 | F32 | 底盘写 | 移动速度 |
| 50030 | U16 | 机械臂写 | 状态反馈：1=空闲, 2=运行中, 3=已完成, 4=故障, 5=急停 |
| 50031 | U16 | 机械臂写 | 故障代码 |
| 50032 | U16 | 机械臂写 | 在位标志：0=不在位, 1=在位 |
| 50040-50045 | 3×F32 | 机械臂写 | 当前X/Y/Z位置 |

### Requirement: 写寄存器回调处理
当底盘写入命令寄存器（50001）时，SHALL 触发对应动作：
- 50001=1 → 执行复位（ClearError + EnableRobot）
- 50001=2 → 回安全位（移动到预设安全位置）
- 50001=3 → 进入自动提钩模式

#### Scenario: 底盘发送复位命令
- **WHEN** 底盘写入 50001=1
- **THEN** 机械臂执行复位操作，状态寄存器更新为"运行中"

### Requirement: 状态寄存器自动更新
服务器 SHALL 定时从 DobotApiFeedBack 读取机械臂状态并更新状态寄存器（50030-50045）。

#### Scenario: 状态更新
- **WHEN** 机械臂连接且反馈数据可用
- **THEN** 每 200ms 更新 50030（状态）、50040-50045（当前位置）等寄存器

### Requirement: GUI Modbus 选项卡
GUI SHALL 新增"Modbus通信"选项卡，显示：
- 服务器启停按钮
- 监听端口配置
- 连接状态（是否有客户端连接）
- 寄存器实时数据表格

#### Scenario: 查看寄存器数据
- **WHEN** 用户切换到 Modbus 选项卡
- **THEN** 可看到所有寄存器地址、含义、当前值的实时表格
